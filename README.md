# CLI-Calculator
Order-of-operation compliant Calculator that uses a command-line interface to interact with its users.

## Roadmap
Currently, I have six versions planned;

-- Version 1 (released)

Version 1 can calculate integers, but not decimals.
Version 1 can handle exponents, factorial, multiplication, division, addition, subtraction, and comparison.
It is also important to note that the formula/equation must be correct; otherwise, it may output an incorrect result or break the program.


-- Version 2 (releases)

In Version 2, minor mistakes in the formula would be corrected through additional programming.

It is important to note that actions like mistakenly using division instead of multiplication would not be corrected, because it is mathematically correct, while it is incorrect intention-wise.


-- Version 3

In Version 3, calculations will support decimal values.


-- Version 4

Version 4 will support parentheses, multiple comparisons, and absolute value.


-- Version 5

Version 5 will support logarithms, trigonometry, modulo, and radical operations.


-- Version 6

Version 6 will support variables.
