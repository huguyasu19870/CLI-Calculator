# CLI-Calculator
Order-of-operation compliant Calculator that uses Comman-line Interface to interact with its users.

## Roadmap
Currently, I have six versions planned;
-- Version 1 (released)
Version 1 can calculate in integer, but not decimal.
Version 1 can handle exponent, factorial, multiplication, division, addition, subtraction, and comparison.
It is also important to note that formula/equation must be correct, otherwise it may output incorrect result.

-- Version 2
In Version 2, minor mistake in formula would be corrected through additional programming.
It is important to note that mistakenly used division instead of multiplication would not be corrected, because it is mathematically correct, while it is incorrect intention wise.

-- Version 3
In Version 3, output will support decimal value.

-- Version 4
Version 4 will support parenthesis, multiple comparisons, and absolute value.

-- Version 5
Version 5 will support logarithm, trigonometry, modulo, and radical operation.

-- Version 6
Version 6 will support variable.
